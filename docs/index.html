기능

Features

꾸밈은 크게, 방해는 없게

Big on style, zero in the way

모서리와 테두리만 씁니다. 미니맵·HUD·채팅은 건드리지 않고, 상대 정보는 보여 주지 않습니다.

Edges and corners only. Minimap, HUD and chat stay untouched; nothing about other players is shown.

챔피언마다 다른 모서리

Corner art per champion

쓰레쉬의 랜턴, 비에고의 검, 자이라의 가시 덩굴. 173명 전부 손으로 그렸고, 전설급 스킨은 따로 그렸습니다.

Thresh's lantern, Viego's blade, Zyra's thorns. All 173 champions hand-drawn; legendary skins get their own art.

스킬·처치·CC 연출

Ability, takedown and CC effects

Q·W·E·R마다 섬광·고리·파동·입자가 테두리를 따라 터집니다. 궁은 화면 전체가 옅게 물듭니다.

Flashes, rings, waves and particles run along the edges for every ability. Ultimates tint the whole screen softly.

직접 만들기

Build your own

부품·색·내 그림(PNG·GIF)을 조합하고 스킬마다 연출을 고릅니다. 코드 없이, 바로 미리보기.

Combine parts, colors and your own PNG/GIF images; pick an effect per ability. No code, live preview.

안전하게

Safe by design

라이엇 공식 Live Client Data API만 읽습니다. 게임 메모리·파일·입력은 건드리지 않습니다.

Reads only Riot's official Live Client Data API. Never touches game memory, files or input.

How it works

Run it, then just play

No installer, no sign-in. It finds your champion when a game starts.

Run

exe를 실행하면 트레이에 상주합니다. 챔피언 화면에서 쓸 챔피언을 켜 두세요.

Riot's API tells it your champion and skin; the matching corner art appears.

FAQ

자주 묻는 것

Questions

 

안전한가요? 제재 위험은요?Is it safe? Can I get banned?

라이엇이 서드파티 앱에 공식으로 열어 둔 Live Client Data API만 읽고, 게임 메모리·파일·네트워크를 건드리지 않으며 입력을 대신 넣지도 않습니다. 상대 정보를 보여 주지도 않습니다.

It reads only Riot's official Live Client Data API, never touches game memory, files or network, never sends input, and never shows information about other players.

어떤 데이터를 쓰나요?What data does it use?

게임 중 내 챔피언·스킨·스킬·자원·체력과 처치 이벤트, 내 스킬 칸·이름표를 작게 캡처해 쿨다운·CC를 알아내는 것(저장·전송 없음), 스킬 키 입력(연출 타이밍용)뿐입니다. 자세한 것은 개인정보 처리방침에.

Your own champion, skin, abilities, resources, health and takedown events during a game; small captures of your own ability bar and name plate to detect cooldowns and CC (never stored or uploaded); your ability keys to time the effects. See the privacy policy.
